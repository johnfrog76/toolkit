## Context
This is a **card**: one Markdown file for one piece of work, kept in your hub at
`demo/backlog/TaskH3RE-start-here-pull-me-onto-the-board.prompt.md`. The file is the record -- what the work was,
what you decided and why, which commits, which pull request. Nothing else holds it, so nothing else can
lose it.

The board works out a card's lane from what the file says. There is no status field to keep up to date:
a commit line moves it to Doing, a pull request to Waiting, the archive to Done.

## Summary
I am in **Backlog**: planned, not yet in play. A new card starts here -- the one you make with the **+**
will too -- and stays here until you pull it. The board reads the folder: `backlog/` is Backlog, and
`current/` is in play.

## Done when
I am in **To do**. Drag me from Backlog to To do, and the file moves from `demo/backlog/` to
`demo/current/`. From a terminal, `Move H3RE -To Active` does the same.

Then the four cards waiting in To do, in this order:

1. *Open me and tick my boxes*
2. *Find out one thing and write it down*
3. *Say "look at this"*
4. *Drop me on Done*
