- A card can name the model that did its work: an `**Agent:** <model id>` line beside `**Assigned:**`,
  read on every tracker and served as the card's `agent`. The lead writes it when signing the card off,
  naming its own model or the builder's it handed the work to, and the build prompt and the how-we-work
  note make that the lead's step. `Config/models.json` maps each id to its provider, family and display
  name, so an id the map does not know is shown as written and never guessed at.
